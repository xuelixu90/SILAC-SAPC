serumsource 使用指南

这份指南写给不懂代码的研究者。你只需要 复制几段代码、改几个路径，就能跑完整个血清来源分析。

目录： 1. 这是什么 2. 准备数据 3. 三步搞定 4. 结果长什么样 5. 换自己的数据怎么改 6. 常见问题

1. 这是什么

serumsource 是一个 R 语言工具包，帮你回答一个问题：

“这个细胞外囊泡（EV）蛋白，到底是血清带进来的，还是 EV 本身的？”

它基于 SILAC 重/轻同位素标记数据，自动算出每个蛋白的“血清来源分数”。

你不需要懂算法，只要会复制粘贴就行。

2. 准备数据

你需要一个 Excel 文件（.xlsx）

来自 MaxQuant 的注释表，里面要有这些列：

列类型列名长什么样是什么
Light 强度Intensity L UCEV_1轻通道蛋白强度
Heavy 强度Intensity H UCEV_1重通道蛋白强度
肽段数Unique peptides UCEV_1鉴定到的唯一肽段数
注释列Protein IDs、Gene names 等蛋白身份信息
记住两个路径：
① Excel 文件在哪（比如 F:/data/my_MaxQuant.xlsx）
② 结果想存到哪个文件夹（比如 F:/data/results）

3. 三步搞定

1

安装工具包（只做一次）

打开 R 或 RStudio，在控制台粘贴：

install.packages("remotes")
remotes::install_github("xuelixu90/SILAC-SAPC")
等它跑完，没有红色 ERROR 就成功了。
2

运行核心分析（一行代码）

把下面代码里的路径改成你自己的：

library(serumsource)

# ===== 只改这一行：换成你的 Excel 文件路径 =====
my_excel <- "F:/data/my_MaxQuant.xlsx"

# 运行分析
core <- run_core_analysis(input_file = my_excel)
控制台会打印进度，比如 Processing: DGEV_PC_1-3_vs_UCEV。
跑完后，结果都存在 core 这个变量里。
3

导出结果（图表 + 表格）

把下面代码里的路径改成你想存结果的文件夹：

# 加载绘图和导出功能
source("downstream/downstream_analysis.R")

# ===== 只改这一行：换成你想存结果的文件夹 =====
my_output <- "F:/data/results"

run_downstream_analysis(
  core_result = core,
  input_file  = my_excel,
  output_dir  = my_output
)
跑完后打开 F:/data/results 文件夹，所有结果都在里面。

4. 结果长什么样

输出文件夹里主要有这些：

results/ ├── Analysis_Report.md ← 先看这个！完整文字报告 ├── plots/ ← 7 张关键图表（PNG） │ ├── classification_summary.png │ ├── excess_distribution.png │ ├── serum_fraction.png │ └── ... ├── 00_Classification_Summary_by_Group.csv ← 每个组分类了多少蛋白 ├── 00_All_Comparisons_Merged_Results.csv ← 每个蛋白的详细结果 ├── 00_All_Comparisons_Primary_Serum_Derived_Merged.csv ← 血清来源蛋白 └── Serum_Source_Analysis_All_Groups_Summary.xlsx ← Excel 汇总表

最关键的几个结果

文件你能看到什么
00_Classification_Summary_by_Group.csv每个实验组里，有多少蛋白被判为“血清来源”
00_All_Comparisons_Primary_Serum_Derived_Merged.csv所有判定为血清来源的蛋白清单（带基因名、数据库证据）
plots/serum_fraction.png每个蛋白的“血清分数”（0~1，越接近 1 越可能是血清来源）
plots/excess_heatmap.png热图：哪些蛋白在哪些组里偏离背景
怎么看分类标签：
高置信 Source-corrected, high confidence — 强证据，血清来源
中置信 Source-corrected, medium confidence — 中等证据
L1 Acquired-only (Level 1) — 对照组无信号但目标组有
背景 Likely_residual / Ambiguous — 不像血清来源

5. 换自己的数据怎么改

如果你的 Excel 列名和默认的不一样，告诉工具包你的列名：

core <- run_core_analysis(
  input_file = "F:/data/my_MaxQuant.xlsx",
  annotation_cols = c(
    protein_ids = "Protein IDs",       # 你的蛋白ID列名
    gene_names  = "Gene names",        # 你的基因名列名
    protein_names = "Protein names",   # 你的蛋白名列名
    in_house_db = "In_house_db",       # 你的数据库列名
    plasma_atlas_db = "Plasma_Altas_db"
  )
)
注意：如果你的实验组名不是默认的（UCEV / DGEV_PC_1-3 等），需要自己建一个映射表。建议找懂代码的人帮忙，或者先用默认数据跑通再改。

6. 常见问题

❓ 报错说“找不到列”

你的 Excel 列名和默认的不一致。看上面第 5 节，用 annotation_cols 指定你的列名。

❓ 报错说“No target groups found”

你的数据里没有默认的对照组名 “UCEV”。用 reference_group 参数指定你的对照组名：

run_core_analysis(input_file = "your.xlsx", reference_group = "你的对照组名")

❓ 结果文件夹是空的

检查 output_dir 路径是否正确，文件夹是否有写入权限。

❓ 怎么只分析某几个组？

用 target_groups 参数：

run_core_analysis(input_file = "your.xlsx",
                  target_groups = c("组A", "组B"))

❓ 怎么让结果更严格/更宽松？

调整阈值参数：

p <- serum_source_params(
  min_absolute_light_excess = 0.10,  # 更大=更严格
  background_multiplier_high = 4     # 更大=更严格
)
run_core_analysis(input_file = "your.xlsx", params = p)
