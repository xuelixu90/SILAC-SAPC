serumsource Usage Guide

Written for researchers who don't code. Just copy a few snippets, change two paths, and the full serum-source analysis runs end to end.

Contents: 1. What it is 2. Prepare your data 3. Three steps 4. What you get 5. Adapting to your own data 6. FAQ

1. What it is

serumsource is an R package that answers one question:

"Is this extracellular-vesicle (EV) protein actually carried by serum, or is it just EV background?"

It uses SILAC Heavy/Light isotope data to automatically compute a "serum-source score" for every protein.

You don't need to understand the algorithm — just copy and paste.

2. Prepare your data

You need one Excel file (.xlsx)

A MaxQuant annotated table that contains these columns:

Column typeExample column nameWhat it is
Light intensityIntensity L UCEV_1Light-channel protein intensity
Heavy intensityIntensity H UCEV_1Heavy-channel protein intensity
Peptide countUnique peptides UCEV_1Number of unique peptides identified
AnnotationProtein IDs, Gene names, etc.Protein identity information
Remember two paths:
→ Where your Excel file lives (e.g. F:/data/my_MaxQuant.xlsx)
→ Where you want results saved (e.g. F:/data/results)

3. Three steps

1

Install the package (once only)

Open R or RStudio and paste into the console:

install.packages("remotes")
remotes::install_github("xuelixu90/SILAC-SAPC")
Wait for it to finish. No red ERROR means success.
2

Run the core analysis (one line)

Change the path below to your own Excel file:

library(serumsource)

# ===== Change this line: your Excel file path =====
my_excel <- "F:/data/my_MaxQuant.xlsx"

# Run the analysis
core <- run_core_analysis(input_file = my_excel)
The console prints progress, e.g. Processing: DGEV_PC_1-3_vs_UCEV.
When it finishes, all results are stored in the variable core.
3

Export results (plots + tables)

Change the path to the folder where you want results saved:

# Load plotting and export functions
source("downstream/downstream_analysis.R")

# ===== Change this line: your output folder =====
my_output <- "F:/data/results"

run_downstream_analysis(
  core_result = core,
  input_file  = my_excel,
  output_dir  = my_output
)
Open the F:/data/results folder — everything is there.

5. Adapting to your own data

If your Excel column names differ from the defaults, tell the package what they are:

core <- run_core_analysis(
  input_file = "F:/data/my_MaxQuant.xlsx",
  annotation_cols = c(
    protein_ids = "Protein IDs",       # your protein ID column
    gene_names  = "Gene names",        # your gene name column
    protein_names = "Protein names",   # your protein name column
    in_house_db = "In_house_db",       # your database column
    plasma_atlas_db = "Plasma_Altas_db"
  )
)
Note: If your experimental group names are not the defaults (UCEV / DGEV_PC_1-3, etc.), you need to build your own sample-mapping table. Ask someone familiar with R for help, or first run the default data to make sure everything works.

6. FAQ

❓ Error: "column not found"

Your Excel column names don't match the defaults. See Section 5 above and use annotation_cols to specify your column names.

❓ Error: "No target groups found"

Your data doesn't contain the default control group name "UCEV". Use the reference_group argument to set your control group name:

run_core_analysis(input_file = "your.xlsx", reference_group = "your_control_name")

❓ The output folder is empty

Check that the output_dir path is correct and the folder is writable.

❓ How to analyse only some groups?

Use the target_groups argument:

run_core_analysis(input_file = "your.xlsx",
                  target_groups = c("GroupA", "GroupB"))

❓ How to make the analysis stricter / more lenient?

Adjust the threshold parameters:

p <- serum_source_params(
  min_absolute_light_excess = 0.10,  # larger = stricter
  background_multiplier_high = 4     # larger = stricter
)
run_core_analysis(input_file = "your.xlsx", params = p)
